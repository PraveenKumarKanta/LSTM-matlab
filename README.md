# Training LSTM Model in MatLAB using Bearing Data for Vibration Analysis.
## Following files are present.
  0. **data_loader.mlx**  [to load signal data from .txt files and save as .mat file]
  1. **data.mat**  [a sample MatLAB data file, for placeholder purposes]
  2. **train_and_predict.mlx**  [Matlab script to run the training and prediction]

To run with your data:

0. DO NOT DOWNLOAD **data.mat** file
1. run data_loader.mlx with data location modified in the line folder = '/Your/data/location/'
2. run train_and_predict.mlx
